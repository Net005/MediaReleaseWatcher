# Vendored provider marks

Downloaded 2026-10-21 from the providers' own repositories/sites. The exact vendored bytes are embedded as data URLs in app.js because the existing static router only allows app.js/styles.css/index.html. The current CSP permits data images. All UI images are served locally; opening a provider is an explicit user navigation, never an external image/tracking request. Marks identify their respective providers, not endorsement. Silo uses the existing neutral film icon because no verified official Silo mark was available.
